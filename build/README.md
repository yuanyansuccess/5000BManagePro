# build —— 环境搭建专区

> 面向**零基础新手**：照着本目录的《环境搭建手册》即可从一台空机器完成安装、调试、部署。

## 目录说明

| 路径 | 用途 |
|------|------|
| `5000B管理系统环境搭建手册.docx` | **保姆级图文手册**（先看这个，一步步照做） |
| `env/check_env.py` | 环境自检工具：一键检查 Python / 依赖 / MySQL / 端口 / 数据库连通性 |
| `env/01_install_deps.bat` | 一键安装后端 Python 依赖（含国内镜像加速） |
| `env/02_init_db.bat` | 一键建库 + 导入初始数据（`database/gjb5000b.sql`） |
| `env/03_start_all.bat` | 一键启动后端(8000) + 前端(8080) |
| `env/工具清单.md` | 需要自行下载的第三方软件清单与官方下载地址 |

## 推荐顺序（新手）

1. 打开 `5000B管理系统环境搭建手册.docx`，按章节顺序做；
2. 每完成一章，可运行 `python build/env/check_env.py` 自检；
3. 全部 `[OK]` 后，双击项目根 `start.bat`（或 `build/env/03_start_all.bat`）启动系统。

## 环境要求速查

- 操作系统：Windows 10/11（64 位）
- Python：3.8+（本项目实测 3.9.7 / Anaconda）
- MySQL：5.7（实测 MySQL Server 5.7，监听 3306，库名 `gjb5000b`，字符集 utf8mb4）
- 浏览器：Edge / Chrome（前端静态页，建议 Edge）
- Word：用于打开生成的《软件开发计划》等文档（2016 及以上）

## 默认账号与端口

| 项 | 值 |
|----|-----|
| 后端 | `http://127.0.0.1:8000`（接口文档 `/docs`） |
| 前端 | `http://127.0.0.1:8080` |
| 数据库 | `127.0.0.1:3306` / 库 `gjb5000b` / 用户 `root` |
| 数据库导入文件 | `database/gjb5000b.sql`（结构 + 全量数据） |
